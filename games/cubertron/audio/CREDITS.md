# CUBERTRON — music credits

Background music is real recorded performances, hosted in this folder. Nothing here is synthesized.
Each file was re-encoded to 96 kbit/s MP3 so the game stays small. Sound effects are synthesized in the browser.
Credits appear on the game's credits screen.

The four pieces shuffle in a random order and a track is not repeated until the others have played.
Playback continues across stages. It does not restart when a level begins.
